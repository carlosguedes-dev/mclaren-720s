# Contribuindo com o Projeto McLaren 720S

Obrigado pelo seu interesse em contribuir com o **McLaren 720S — Experiência Digital & Quiet Luxury**! Este projeto é uma vitrine de engenharia front-end purista e design editorial automotivo de alto padrão.

---

## 🏎️ Como Contribuir

1. Faça um **Fork** do repositório
2. Crie uma nova branch para a sua feature ou melhoria arquitetural (`git checkout -b feature/nova-animacao-canvas`)
3. Faça suas alterações mantendo os padrões de código limpo e design sobrio (sem bibliotecas externas pesadas ou utilitários intrusivos)
4. Realize o commit de suas alterações com mensagens claras (`git commit -m 'feat: aprimora interpolação de quadros no canvas'`)
5. Faça o push para a branch no seu fork (`git push origin feature/nova-animacao-canvas`)
6. Abra um **Pull Request (PR)** descrevendo detalhadamente as melhorias propostas

---

## 📐 Diretrizes de Design & Código (Padrão "Quiet Luxury")

Para mantermos a excelência e o padrão das campanhas da McLaren Automotive, solicitamos atenção aos seguintes princípios:
- **Zero Emojis Informais:** Utilize tipografia sóbria, pontos arquitetônicos (`.col-dot`) ou ícones SVG vetoriais minimalistas.
- **Respiro Visual (Whitespace):** Evite excesso de caixas em torno de textos e grids. O design deve priorizar o contraste natural, a leveza e a clareza editorial.
- **Performance Nativa (Vanilla JS):** O motor de animação e scroll deve se manter 100% em JavaScript nativo para máxima eficiência na aceleração por hardware e economia de memória.

---

## 🐛 Reportando Bugs e Sugestões

Se você encontrar alguma instabilidade na renderização do Canvas, gargalo em dispositivos móveis ou tiver ideias para expansão da ficha técnica, abra uma **Issue** no repositório descrevendo o comportamento com o máximo de detalhes possível (incluindo resolução de tela e navegador).
